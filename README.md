# XT Tarkov Overlay - 3D-модели оружия

Детали оружия для 3D-просмотра в «Снаряжении» программы XT Tarkov Overlay. Программа скачивает отсюда только детали открытой сборки
и хранит их в кэше; сайт отдаётся через GitHub Pages.

- `catalog.json` - стволы, штатные сборки, слоты;
- `pack/<id предмета>.bin` - геометрия детали, `pack/tex/*.webp` - текстуры 256 px;
- `orient.json`, `rootq.json`, `slotq.json`, `partfix.json`, `slotfix.json` - как ставить детали в точки крепления.

Модели и текстуры - из игры Escape from Tarkov, © Battlestate Games. Используются некоммерчески, для сообщества игроков;
по запросу правообладателя будут удалены.
